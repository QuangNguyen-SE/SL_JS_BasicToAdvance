# Built-in function:
- Built-in function là các hàm xây dựng sẵn trong javascript
- Có vô số hàm built-in function.
- Nhưng có 6 hàm cơ bản cần biết:
    1. Alert : thông báo
    2. Console : in ra 
    3. Confirm : xác nhận
    4. Prompt : xác nhận + ô nhập
    5. Set timeout : Ấn định sau bao lâu nó sẽ chạy
    6. Set interval : Sau 1 khoảng thời gian nó sẽ lặp lại
